rclone-backup

A private backup setup used by one person. Once a day it copies files from their own Mac into their own Google Drive, encrypted before they leave the computer.

  1. Owner's Macfiles and projects
  2. resticencrypts and versions
  3. rcloneuploads
  4. Owner's Google Drivebackup folder

Who uses it

Only its owner. It is not offered to anyone else, has no sign-up and no other users.

What it can access

The owner's own Google Drive, so it can write new backups to a backup folder and read them back when files need to be restored.
